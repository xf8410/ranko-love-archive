### 算法流程
```
1. 将Key转为8字节小端: 6ee63806d4cd8095
2. 对每个BaseKey字节: keys[i*8+j] = BaseKey[i] ^ keyBytes[j]
3. 得到88字节的keys数组
4. 跳过前256字节(保持不变)
5. data[i] ^= keys[i % 88]
```

## 对hlpatch/uma-juece的适用性

### ✅ 可直接解密
- **master.mdb**: SQLCipher加密数据库，使用decrypt-db命令
  - 日服密钥: 32字节 XOR DB_BASE_KEY
  - Global服密钥: 12字节 XOR DB_BASE_KEY
  - 需要sqlite3mc库

- **dat/资源文件**: XOR循环加密
  - 使用decrypt-dat命令
  - 需要meta数据库中的密钥索引

### ❌ 不适用
- **libil2cpp.so**: Coneshell保护（内存壳），需运行时Frida hook
- **global-metadata.dat**: IL2CPP元数据混淆，需Il2CppDumper
- **MessagePack数据**: 未加密，直接用MsgPackDecoder解码

## 实际使用命令

```bash
# 解密游戏数据库
UmaDecryptor.exe decrypt-db -i meta -o meta_decrypted -v

# 解密游戏资源
UmaDecryptor.exe decrypt-dat -i "dat" -o "dat_decrypted" -m "meta_decrypted"

# 一键处理整个游戏目录
UmaDecryptor.exe uma-dir -i "C:\Users\...\umamusume" -o "C:\UMA_Decrypted" -v

# Python版本（本仓库提供）
python3 tools/uma_decrypt.py generate-keys
python3 tools/uma_decrypt.py decrypt-dat <input_dir> <output_dir> <meta_db>
```
