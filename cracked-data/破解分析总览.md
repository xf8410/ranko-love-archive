# 破解分析总览

## 破解目标

| 仓库 | 待破解内容 | 加密方式 | 破解工具 | 状态 |
|------|-----------|----------|----------|------|
| hlpatch | master.mdb | SQLCipher | UmaDecryptor decrypt-db | ✅ 可解密 |
| hlpatch | dat/资源文件 | XOR循环 | UmaDecryptor decrypt-dat | ✅ 可解密 |
| hlpatch | libil2cpp.so | Coneshell壳 | Frida运行时hook | ❌ 需手机 |
| hlpatch | global-metadata.dat | IL2CPP混淆 | Il2CppDumper | ❌ 需PC |
| uma-juece | MsgPack训练数据 | 无加密 | MsgPackDecoder | ✅ 已解码 |
| uma-juece | HTTP通信 | 明文 | 直接读取 | ✅ 无需解密 |

## 解密算法核心

### 数据库 (SQLCipher)
```
DB_BASE_KEY = [F1,70,CE,A4,DF,CE,A3,E1,A5,D8,C7,0B,D1,00,00,00]
最终密钥 = 原始密钥 XOR DB_BASE_KEY[0:13]
```

### 资源文件 (XOR)
```
BaseKeys = [53,2B,46,31,E4,A7,B9,47,3E,7C,FB]
Key = -7673907454518172050 (0x958F6B5A3D2E1C2E)
跳过前256字节 → 循环XOR
```
