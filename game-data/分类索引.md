# 游戏数据分类索引

## 数据来源
- `umaDB (1).json`：用户上传，赛马娘角色数据
- `cardDB(1).json`：用户上传，赛马娘支援卡数据

## 文件结构
```
game-data/
├── umaDB/
│   ├── umaDB_full.json          # 完整角色数据 (259名)
│   ├── 角色数据总览.md           # 基础概览
│   └── 角色深度分类.md           # 按成长率/属性分类
├── cardDB/
│   ├── cardDB_full.json          # 完整支援卡数据 (543张)
│   ├── 支援卡数据总览.md         # 基础概览
│   └── 支援卡深度分类.md         # 按类型/稀有度分类
└── 分类索引.md                   # 本文件
```

## 快速导航

### 角色数据
- **总览**：259名角色，131个角色ID，99个多换装
- **成长率最高**：30%（特别周、东海帝王、丸善斯基等）
- **速度型**：以速度成长为主的角色
- **耐力型**：以耐力成长为主的角色
- **力量型**：以力量成长为主的角色
- **根性型**：以根性成长为主的角色
- **智力型**：以智力成长为主的角色

### 支援卡数据
- **总览**：543张卡，速121/耐93/力98/根106/智97/友23
- **SSR最多**：速度型69张
- **得意率最高**：80%（伏特加、青云天空、目白赖恩等）
- **友情训练最高**：37.5%（菱亚马逊、美浦波旁等）

## 交叉分析
可以使用 `tools/cross_analysis.py` 进行角色×支援卡交叉分析。
