# 赛马娘支援卡数据 (cardDB)

## 数据来源
- 来源：用户上传 `cardDB(1).json`
- 条目数：543 张支援卡
- ID范围：10001 ~ 30306

## 数据结构
每张支援卡包含以下字段：
- `cardId`: 卡片ID
- `charaId`: 角色ID
- `cardName`: 卡片名称
- `fullName`: 完整名称
- `rarity`: 稀有度 (1=R, 2=SR, 3=SSR)
- `cardType`: 卡片类型 (0=速, 1=耐, 2=力, 3=根, 4=智, 5=友人)
- `cardValue`: 各突破等级的详细数值
  - `filled`: 是否已填数据
  - `bonus`: 训练加成 [速,耐,力,根,智,友情]
  - `initialBonus`: 初始加成
  - `hintBonus`: Hint加成
  - `hintLevel`: Hint等级
  - `youQing`: 友情训练值
  - `ganJing`: 干劲加成
  - `initialJiBan`: 初始羁绊
  - `hintProbIncrease`: Hint概率提升
  - `deYiLv`: 得意率
  - `saiHou`: 赛后加成 (部分卡片)
